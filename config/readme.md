# TrustVault – Secure Document Sharing System

## Project Description
TrustVault is a web-based application developed using Python and Django. It allows users to securely upload, manage, view, download, and share documents with other registered users.

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite
- Git and GitHub

## Features
- User Registration and Login
- Secure User Dashboard
- Document Upload
- Document Search
- Document Sharing
- View and Edit Documents
- User Permission Management
- Revoke Document Access
- Secure Document Download
- Activity History

## Installation

1. Clone the repository:
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:
   cd TrustVault-Secure-Document-Sharing

3. Install Django:
   py -m pip install django

4. Apply migrations:
   py manage.py migrate

5. Start the server:
   py manage.py runserver

6. Open in your browser:
   http://127.0.0.1:8000/
